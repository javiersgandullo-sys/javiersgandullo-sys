# Javier Sánchez Gandullo

Hago webs y programas a medida para negocios pequeños: desde la web de una empresa hasta
el programa de gestión entero de una autoescuela o el TPV de una tienda de barrio.

Casi todo es trabajo para clientes y el código está en repos privados, así que aquí cuento
qué tipo de cosas he montado. Si necesitas algo parecido, escríbeme.

## Algunos trabajos

**AGE-X, gestión para autoescuelas.** Mi proyecto más grande, y mío: ya lo usan varias
autoescuelas. Lleva alumnos, profesores, clases prácticas y teóricas, exámenes, caja y
recibos. Cobra con tarjeta y Bizum, avisa por WhatsApp, tiene fichaje con QR para el
personal, rellena los documentos de la DGT y cada autoescuela activa solo los módulos que
usa. Laravel con React (Inertia), y se puede instalar en el móvil como app.

**TPV para una tienda de alimentación.** Programa de escritorio en Python y PySide6:
lector de códigos de barras, impresora de tickets, cajón, stock, proveedores y cuentas
de clientes que pagan a final de mes. Lee las facturas de los proveedores a partir de una
foto para actualizar precios. Importa los productos del TPV que tenían antes.

**Facturación para autónomos.** Aplicación de Windows en C# y WPF para hacer facturas y
presupuestos sin depender de internet ni de cuotas. Todo queda en el ordenador del
cliente, en un único archivo.

**Webs con panel propio.** Webs de empresa (eventos, ocio, estructuras metálicas) en las
que el cliente cambia textos, fotos y fichas sin llamarme. También un portal inmobiliario
con búsqueda dibujando zonas en el mapa, anuncios con fotos y vídeo y pagos con Stripe.

## Con qué trabajo

- Webs: TypeScript, Next.js, React, Astro, PHP y Laravel
- Datos: Supabase y Postgres, MySQL y SQLite
- Hosting: Cloudflare Workers, Vercel y servidores propios
- Escritorio: Python con PySide6, C# con .NET y WPF
- Pagos y avisos: Stripe, Redsys y la API de WhatsApp Business
