# Javier Sánchez Gandullo

Hago webs y programas a medida para negocios pequeños: desde la web de una empresa hasta
el programa de gestión entero de una autoescuela o el TPV de una tienda de barrio.

Casi todo es trabajo para clientes y el código está en repos privados, así que aquí cuento
qué tipo de cosas he montado. Si necesitas algo parecido, escríbeme.

## Algunos trabajos

- **AGE-X**: gestión para autoescuelas (alumnos, clases, exámenes, cobros, fichaje, documentos de la DGT). Es mío y ya lo usan varias autoescuelas.
- **TPV para una tienda de alimentación**: escritorio en Python, con lector de códigos, tickets, stock y fiado.
- **Facturación para autónomos**: aplicación de Windows en C# que funciona sin internet.
- **Webs con panel propio**: para empresas de eventos, ocio y estructuras metálicas, y un portal inmobiliario con búsqueda en mapa.

## Con qué trabajo

- Webs: TypeScript, Next.js, React, Astro, PHP y Laravel
- Datos: Supabase y Postgres, MySQL y SQLite
- Hosting: Cloudflare Workers, Vercel y servidores propios
- Escritorio: Python con PySide6, C# con .NET y WPF
- Pagos y avisos: Stripe, Redsys y la API de WhatsApp Business
